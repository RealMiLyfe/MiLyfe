# Contributing to MiLyfe

Thank you for your interest in contributing to MiLyfe! We welcome contributions from the community.

## How to Contribute

1. **Fork the repository** on GitHub
2. **Clone your fork** locally
3. **Create a branch** for your work following our branch naming conventions
4. **Make your changes** following our coding standards
5. **Run tests** to ensure your changes don't break existing functionality
6. **Commit your changes** with clear, descriptive commit messages
7. **Push to your fork** and submit a pull request

## Development Workflow

### Before You Start
- Read the README and AGENTS.md files
- Check for existing issues related to your work
- Ensure your development environment is set up correctly

### Making Changes
- Follow the agent session protocol: read steering files, current state, and active risks before starting
- Stay within the scope of your assigned issue
- Keep branches short-lived and focused on one coherent change
- Never commit directly to protected branches
- Never work on another contributor's branch without explicit handoff

### Code Standards
- Write clear, well-documented code
- Follow existing code patterns and conventions
- Include tests for new functionality
- Ensure all automated checks pass before submitting a pull request
- No hardcoded secrets or credentials
- No console.log or debug statements in production code

### Pull Request Process
1. Ensure your branch is up to date with the target branch
2. Run all required tests and checks
3. Update documentation as needed
4. Complete the handoff template
5. Submit your pull request with a clear description
6. Request appropriate reviews based on the impact of your changes
7. Address feedback from reviewers promptly
8. Make any requested changes
9. Maintainers will merge approved pull requests

## Reporting Issues
- Use the issue templates provided
- Include steps to reproduce for bug reports
- Provide clear descriptions for feature requests
- Label issues appropriately

## Getting Help
- Check the documentation in the docs/ directory
- Review existing issues and pull requests
- Ask questions in the appropriate channels

We appreciate your contributions to MiLyfe!
