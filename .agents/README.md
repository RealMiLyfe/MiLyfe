# MiLyfe Agents Directory

This directory contains agent-related configurations, roles, skills, and prompts for the MiLyfe agent orchestration system.

## Directory Structure

- `roles/` - Definitions of different agent roles and their responsibilities
- `skills/` - Specialized capabilities that agents can be equipped with
- `prompts/` - Standardized prompts for different agent types and tasks

## Usage

Agents should consult the appropriate files in this directory when:
- Understanding their role and responsibilities
- Equipping themselves with necessary skills
- Following standardized prompts for common tasks

See the root `AGENTS.md` for overall agent guidelines and the repository steering files in `docs/agent/` for current state and coordination information.
